# Football Explorer ⚽

Sistema de consulta e automação para busca de clubes e ligas de futebol utilizando a **API-Football v3** e persistência de dados no **Supabase**.

## 🚀 Funcionalidades

- **Busca por Países:** Filtre ligas e copas por país.
- **Busca por Ligas/Copas:** Dropdown pesquisável para encontrar competições específicas.
- **Temporadas:** Seleção automática de temporadas disponíveis.
- **Integração Supabase:** Salvamento em lote de clubes encontrados, evitando duplicatas.
- **Logs em Tempo Real:** Acompanhamento de todas as requisições à API.

## 🛠️ Tecnologias

- **HTML5 / CSS3 (Vanilla)**
- **JavaScript (Vanilla)**
- **Supabase** (Banco de dados e Cliente JS)
- **API-Football** (API de Terceiros)
- **Google Fonts** (Bebas Neue & DM Sans)
